Ingeniería seria, no un script con suerte.

ResumiBot es un SaaS multi-tenant en producción, construido y operado por Starling Germosen. Cada pieza del pipeline está integrada y automatizada:

IA multi-proveedor: OpenAI · Anthropic Claude · Google Gemini Voz: Whisper (transcripción) · voces neuronales Edge-TTS · clonación XTTS Video: avatares HeyGen / D-ID / SadTalker · FFmpeg Pagos: suscripciones PayPal con webhooks verificados Backend: Node.js + Express · motor de medios en Python Datos: SQLite WAL multi-tenant (40+ tablas) · backups automáticos Infra: VPS Ubuntu · PM2 · Nginx + SSL · CI/CD con GitHub Actions · watchdog Seguridad: JWT · bcrypt · rate limiting · claves BYOK cifradas · webhooks HMAC

BYOK = cada cliente puede conectar su propia clave de OpenAI/Claude/Gemini, con cuotas mensuales y fallback automático a la clave de la plataforma.

Preguntas frecuentes

Lo que todos preguntan.

¿Cómo se conecta ResumiBot a mi WhatsApp?

Mediante emparejamiento con código QR, igual que WhatsApp Web. Necesitas un número aparte para el bot — nunca el tuyo personal. Es una conexión no oficial y WhatsApp puede bloquear números por uso automatizado; con una línea dedicada tu número personal nunca está en juego. En resumibot.com/chip está explicado qué chip usar y qué no hacer con él.

¿Mis mensajes están seguros?

Cada cliente (tenant) tiene sus datos completamente aislados, las claves de IA se guardan cifradas, el acceso al panel usa JWT y contraseñas con hash bcrypt, y los datos antiguos se depuran automáticamente según la política de retención.

¿Puedo usar mi propia clave de OpenAI, Claude o Gemini?

Sí — es el modelo BYOK (Bring Your Own Key). Conectas tu clave y consumes directo de tu cuenta del proveedor, sin el límite mensual del plan (con topes técnicos razonables contra abuso). Si tu clave falla, el sistema cae automáticamente a la clave global para no interrumpir el servicio.

¿Sirve para negocios, no solo para grupos?

Sí. ResumiBot incluye un modo negocio completo: respuestas automáticas, horarios, bienvenidas, captura de leads, seguimiento de clientes, difusiones, plantillas y hasta respuesta inteligente con IA usando el contexto de tu empresa.

¿Está en inglés y portugués?

Sí. Las páginas del producto están en resumibot.com/en/ y resumibot.com/pt/, el bot escribe los resúmenes en el idioma que elijas en Voz del Bot, y el portal del cliente se puede usar en español, inglés o portugués.

¿Puedo tener ResumiBot con mi propia marca?

Sí. La plataforma es multi-tenant y puede desplegarse como instancia dedicada white-label para tu empresa o para revender el servicio. Escríbeme a sgermosen@outlook.com y armamos la implementación.
