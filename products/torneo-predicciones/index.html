Tecnología

Una base sólida, lista para relanzar.

Producto de Starling Germosen. App funcional de punta a punta con backend en Azure — lista para implementarse con tu marca, o para modernizarse a .NET 8 / MAUI como parte del proyecto.

App: Xamarin.Forms (iOS · Android) · MVVM · SQLite offline Backend: ASP.NET Core · API REST · panel Razor · Identity Nube: Microsoft Azure · SQL Azure · Notification Hubs (push) Extras: login Facebook · emails de confirmación y recuperación (MailKit) · validación anti-inyección
Preguntas frecuentes

Rápidas y al grano.

¿Esto es una app de apuestas?

No. Es un juego de precisión y orgullo deportivo: los puntos se ganan por acertar, no se apuesta dinero dentro de la app. Las "apuestas amistosas" son retos entre amigos fuera de la plataforma.

¿Puedo usarla para el próximo mundial o la temporada de LIDOM?

Sí — cualquier competencia que pueda organizarse como liga con equipos, torneos y partidos se puede montar desde el panel administrativo en minutos.

¿Qué incluye el licenciamiento?

La plataforma completa: app iOS/Android con tu marca, backend con panel administrativo, configuración de tus torneos y acompañamiento en el lanzamiento. Opcionalmente, modernización del stack a .NET 8 / .NET MAUI. Escríbeme a sgermosen@outlook.com.
